# Template para oficinas — Indaiatuba

Modelo demonstrativo responsivo com marca fictícia Torque. Abra `index.html` para visualizar. O painel “Personalizar modelo” permite simular nome, cor e WhatsApp; as escolhas ficam apenas no navegador, não alteram a versão publicada para outros visitantes.

Para entregar a um cliente, substitua os valores padrão de `script.js`, a marca e os textos de `index.html`, endereço, horários, serviços efetivamente oferecidos e a fotografia ilustrativa. Atualize título e descrição. Remova a faixa demonstrativa e o painel de personalização na versão final. Não há backend nem coleta de leads: o formulário prepara uma mensagem que o visitante envia no WhatsApp.

Fontes Google Fonts e fotografia remota do Unsplash dependem de conexão. Revise os direitos dos recursos e use fotos autorizadas da oficina antes da entrega comercial.
